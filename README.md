# Lumina AI

An AI-powered creative workspace with chatbot, image generation, voice studio, document analysis, notes, credits, and user authentication.

## Features

- AI Chatbot
- Image Studio
- Voice Studio
- Document Studio
- Notes and downloads
- Activity history
- Prompt templates
- User authentication
- Gmail verification
- Credit and plan system

## Tech Stack

- HTML
- CSS
- JavaScript
- FastAPI
- MongoDB Atlas
- Gemini API
